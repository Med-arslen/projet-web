Installation
Clonez le dépôt Git :
git clone https://github.com/Med-arslen/projet-web.git

Placez le projet dans le répertoire racine de votre serveur web (par exemple, htdocs pour XAMPP).

Configurez la base de données dans le fichier config.php.

Importez le fichier SQL fourni pour créer les tables nécessaires.

Utilisation
Accédez à l'application via votre navigateur à l'adresse :
http://localhost/projetweb/View/index.php
Utilisez l'interface pour gérer les réclamations et les feedbacks.
