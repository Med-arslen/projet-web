A complete event reservation system built with PHP and MySQL. Users can explore films, make and pay for reservations, and view their history. Admins have a powerful backoffice to manage events, view reservations, and generate reports.

Features
FrontOffice (User Side)
Browse a list of available films

Make event reservations

Online payment simulation

View reservation history

Integrated chatbot for help and guidance

User login and session management

BackOffice (Admin Side)
Add, update, delete film events

Search and sort events

Generate a QR code for each event

View all user reservations delete reservation

Generate PDF summaries of reservations
