# 🌐 Projet Web - Backoffice & Front

Ce projet est une plateforme web complète, composée de deux parties principales :

- **🔒 Backoffice** : Une interface d'administration pour la gestion des contenus, des utilisateurs et des configurations.
- **🌍 Projet** : La partie front-end visible par les visiteurs, avec une interface utilisateur dynamique et interactive.

## 🗂️ Structure du projet

proj web/ ├── backoffice/ # Interface d’administration └── projet/ # Site principal visible par les utilisateurs


## 🚀 Instructions d’installation

1. Cloner le dépôt Git :
   ```bash
   git clone https://github.com/Med-arslen/projet-web.git
Naviguer dans le dossier :


cd "projet-web"
Lancer votre serveur local (ex. XAMPP, Laragon, WAMP, etc.)

Placer le dossier dans htdocs/ si vous utilisez XAMPP

Accéder via : http://localhost/projet
